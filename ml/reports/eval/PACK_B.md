# Шаг 11, пакет B: оставленный предмет и «забрал другой» — проверка (25.11.2026)

Правила `abandoned_object` и `object_taken` (логика — `src/vision/analytics/objects.py`). Типы schema 1.1,
**ждут одобрения BE**: ML пишет их в лог, в MQTT не отправляет. Лиц нет (решение BE: инцидент на проверку,
не доказательство кражи). Предметы ищет тот же детектор (COCO: рюкзак, сумка, чемодан, ноутбук) за тот же
прогон — только на камерах с этими правилами; у предметов свой ByteTrack на камеру (помнит 5 с).

## Сценарии (синтетика, `tests/test_rules_pack_b.py` — сцены O1–O8 из `docs/shooting_plan.md`)

| сцена | ожидание | результат |
|---|---|---|
| O1 принёс, поставил, ушёл из кадра | abandoned_object, участников нет | ✓ |
| O1 владелец стоит далеко, но в кадре | abandoned_object, участник — владелец | ✓ |
| O2 вернулся и забрал своё | ничего | ✓ |
| O3 оставил, чужой подошёл и унёс | object_taken, участник — кто унёс | ✓ |
| O4 передал из рук в руки при себе | ничего | ✓ |
| O5 сумка у ног сидящего | ничего | ✓ |
| смена ID владельца у сумки | ничего (кто рядом ≥ 5 с — «присматривает») | ✓ |
| O6 владелец вернулся с новым ID | ничего (узнали по цвету одежды) | ✓ |
| прохожий заслонил сумку и ушёл | ничего (появилась на месте — не кража) | ✓ |
| сумка исчезла вместе с чужим, он ушёл | object_taken | ✓ |
| прошёл с сумкой через кадр | ничего | ✓ |
| предмет в кадре с самого начала (ноутбук на столе) | ничего — часть сцены | ✓ |

Контроль (тесты не «зелёные впустую»): чужой в другой одежде → object_taken; без сравнения одежды
O6 даёт ложное object_taken; передача без владельца рядом → object_taken.

## Ложные на обычном видео (ТЗ 18)

RWF-2000 dev, 800 роликов без драк (1.1 ч: офисы, магазины, улицы), **стресс-режим** `abandon_s=3`
(в жизни 30 с): [fight_dev_20261125-0149_pack-b-fp](fight_dev_20261125-0149_pack-b-fp.md).

| правило | ложных | ложных в час |
|---|---|---|
| abandoned_object | 0 | 0 |
| object_taken | 0 | 0 |

До исправления было 19 ложных «оставили» на 14 роликах: ноутбуки на столах в офисах и стулья, которые
детектор принял за сумку/чемодан (0.26–0.45), — всё, что стоит в кадре с начала. Исправлено определением:
«оставленный» — только тот предмет, который на глазах **принесли**.

## Ограничения (честно)

- **Находки на реальном видео не проверены**: нет ролика, где сумку оставляют. PETS 2006 (публичный датасет
  оставленного багажа) сейчас недоступен (сервер не отвечает); основной путь — постановочные сцены O1–O8.
- YOLO26n слабо видит предметы в толпе: на demo1 сумки в руках находятся редко (уверенность 0.1–0.45),
  за 16 с подтвердился 1 трек предмета. Мелкие предметы (телефон, кошелёк) не поддержаны.
- Владелец определяется по треку + цвету одежды; в плотной толпе возможны ошибки — поэтому сигнал на проверку.
- Если система запущена, когда сумку уже оставили, — это «часть сцены» (не тревога).
