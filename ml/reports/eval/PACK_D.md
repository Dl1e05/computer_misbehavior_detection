# Шаг 11, пакет D: изменение охраняемого объекта (сигнал вандализма) — проверка (25.11.2026)

Правило `scene_change` (`src/vision/rules/scene_change.py`). Тип schema 1.1 по определению, отправленному BE
25.11: «охраняемая зона (дверь, окно, стенд) заметно и надолго изменилась относительно эталона, и незадолго
до этого рядом был человек». Инцидент на проверку, не доказательство порчи; лиц нет; пока только лог.

Как отличает порчу от всего остального:

| что мешает | чем отсекается |
|---|---|
| свет (включили/выключили, облако) | кадр и эталон нормируются по яркости внутри зоны — меняется только «рисунок» |
| человек стоит перед объектом | кадры, где люди закрывают ≥ 10% зоны, не оцениваются; пиксели под людьми не считаются |
| мелькание, тень от прохожего | изменение должно держаться `hold_s` (5 с) |
| сдвинулась вся сцена (поворот камеры, панорама) | зона должна измениться сильнее своей окрестности (кольца вокруг) — иначе это camera_tampering |
| «само изменилось» (без людей) | нужен человек рядом за `person_window_s` (60 с) до начала изменения |
| одна порча — много тревог | одно событие; через `relearn_s` новый вид становится эталоном |

## Синтетика (`tests/test_rules_pack_d.py`, 7 тестов)

Порча двери после визита человека — событие (участник — он, доля 0.45); сильная смена света, изменение без
людей, человек заслоняет дверь 20 с, наклейка на 10% двери, мелькание 2 с, сдвиг всей сцены — ничего;
повторная порча после переучивания — второе событие. Контроль: без нормировки по яркости смена света даёт
ложное событие (изменилось 100% зоны) — значит, тест действительно проверяет нормировку.

## Реальный ролик (`scripts/make_scene_change_clip.py`: demo2 — площадь, люди ходят)

Охраняемый объект — рольставня киоска. 0–8 с норма, 8–14 с весь кадр темнее, 14–16 с норма, 16–30 с «граффити».

- событие **одно, на 21.2 с** (граффити с 16 с + 5 с удержания), доля изменения 0.52, участники — люди,
  проходившие рядом; на затемнении — ничего;
- находка: demo2 снят **медленно панорамирующей камерой** — рольставня «уплывала» из зоны, и доля изменения
  до граффити доходила до 0.34 (порог 0.25) — почти ложное событие. Добавлено сравнение с окрестностью:
  превышение над кольцом до граффити 0.12–0.22, на граффити 0.42–0.52.

## Ограничения

- Ложные в час на обычном видео не замерены: правило привязано к охраняемым зонам конкретных камер —
  нужны постановочные сцены V1–V3 и час обычной жизни W1 (`docs/shooting_plan.md`).
- «Удары по объекту» по позе и видео-модель вандализма — исследование (R1), без тревог (ТЗ 18.3).
- Если объект изменили, пока его заслонял человек, и человек так и стоит — оценка ждёт, пока зону откроют.
