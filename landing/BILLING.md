Цена фиксируется за план в пределах указанных лимитов. Все планы включают оповещения о подозрении на вандализм. Годовая предоплата со скидкой 15% экономит 53 820 ₸, 179 820 ₸ и 449 820 ₸ соответственно. При полном использовании лимита месячная цена в пересчете на камеру составляет 7 475 ₸, 6 243,75 ₸ и 5 206,25 ₸. Цены и лимиты пока гипотезы для пилотов в Казахстане. Отдельно оцениваются оборудование, монтаж, настройка и архив видеозаписей.

Для гибридного развертывания университет использует существующие камеры, а распознавание выполняется на локальном оборудовании. В облаке размещаются метаданные инцидентов, административная панель и сервис уведомлений. На пилоте стоит замерить одновременную нагрузку на обработчик, время до оповещения, долю ложных тревог и нагрузку на службу поддержки.

Для полностью облачного варианта сначала нужен замер GPU-расхода на активный камера-час при целевых параметрах видео и одновременной нагрузке. Месячная оценка равна этому расходу, умноженному на суммарное число активных камера-часов, плюс хранение, поддержка, доставка сообщений и комиссия платежного провайдера. Замеры и коммерческие условия нужны до расчета рентабельности.

## Как принимать оплату

1. Начать с B2B-пилота по заявке. Команда согласует состав пилота, подключение, сроки, реквизиты и договор, затем выставляет счет для оплаты банковским переводом. Лендинг позволяет скачать черновик запроса в KZT на свое устройство.
2. После подтверждения спроса добавить разовую оплату по ссылке на странице провайдера. Сначала подтвердить договорное подключение юрлица, расчеты в KZT, сроки зачисления, комиссии, порядок возвратов и требования к документам.
3. Добавлять автоматическое списание после появления спроса на продление. До первого списания получить согласие на сумму и периодичность. При неудачной оплате уведомить клиента, ограничить число повторов и применить заранее оговоренный льготный период. При отмене сохранить доступ до конца оплаченного срока и прекратить дальнейшие списания. Возвраты учитывать отдельно от отмены продления.

FreedomPay и Halyk стоит сравнить на этапе разового платежа. У FreedomPay рекуррентный профиль требует включения функции через менеджера. Первый платеж создает профиль через `pg_recurring_start=1`, а результат приходит на `pg_result_url`. Если ответ потерян, перед повтором нужно сверить состояние операции по `pg_order_id`. [Документация FreedomPay](https://docs.freedompay.kz/create-recurring-payment-21166426e0)

У Halyk есть платежная страница и сценарий оплаты сохраненной картой с `cardID` и признаком рекуррентного платежа. CloudPayments KZ описывает рекуррентные платежи, детали API и подключения нужно подтвердить у провайдера. [Платежная страница Halyk](https://epayment.kz/ru/docs/platezhnaya-stranica), [Оплата сохраненной картой Halyk](https://epayment.kz/docs/platezh-po-sokhranennoi-karte), [CloudPayments KZ](https://cloudpayments.kz/)

Казахстан отсутствует в списке стран Stripe для подключения продавца. Вариант со Stripe зависит от юрисдикции юрлица и соответствия его требованиям. [Список стран Stripe](https://stripe.com/global)

## Будущая интеграция

Предлагаемый стек для платежного сервиса - FastAPI >=0.162 и асинхронный SQLAlchemy >=2.1.6. Сервер определяет организацию по авторизованному пользователю, рассчитывает сумму и валюту по тарифу и периоду, создает заказ и выдает ссылку на страницу провайдера. Карточные данные принимает и хранит провайдер.

Оплата подтверждается после проверки подписи и успешного статуса платежа в webhook, а также сверки ID заказа, суммы и валюты с данными сервера. Обработчик идемпотентно фиксирует платеж и активацию доступа в одной транзакции. Возврат покупателя с платежной страницы служит для показа статуса заказа. Потерянные ответы сверяются с провайдером перед повторной попыткой.

## Расчет и скачивание черновика

В `landing/index.html`, строки 713-717, цена за год вычисляется из месячной ставки и скидки. Эту функцию используют итог в форме и текст черновика.

```js
const annualDiscount = 0.15;
const quoteAmount = () => {
  const monthly = plans[plan.value].monthly;
  return period.value === "year" ? Math.round(monthly * 12 * (1 - annualDiscount)) : monthly;
};
```

В `landing/index.html`, строки 752-757, браузер формирует текстовый файл и запускает его скачивание.

```js
const url = URL.createObjectURL(new Blob(["\uFEFF", lines.join("\r\n")], { type: "text/plain;charset=utf-8" }));
const link = document.createElement("a");
link.href = url;
link.download = `crimetor-${plan.value}-request.txt`;
link.click();
setTimeout(() => URL.revokeObjectURL(url), 1000);
```
