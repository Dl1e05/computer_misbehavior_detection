# План постановочных съёмок (D3)

Зачем: метрики на своих камерах (шаг 10), обучение драки (Фаза 3.2), порог лиц (3.5) и данные для новых
функций (кражи, проход вдвоём, саботаж, вандализм-сигнал). Снимаем **один раз всё сразу** — повторно
собирать добровольцев, согласия и место дорого.

## Правила (ТЗ 5.2, 12.4, 13.4)

- Только взрослые добровольцы с **письменным согласием**: на видеосъёмку и **отдельно** на биометрию (лица).
  Форму согласия согласовать с руководителем и университетом до съёмок.
- Ответственный за безопасность на площадке. Падения — только на маты. Драки — отрепетированные,
  без реальных ударов (удары мимо, толчки в плечо). Вандализм — только по макету (фанера, картон), ничего не ломаем.
- **Огонь вживую не снимаем.** Для огня — D-Fire и снятые нами негативы (лампы, экраны, закат).
- Снимаем **теми же камерами и с тех же точек**, что на стенде, плюс 1–2 запасных ракурса.
- Записи с людьми хранятся только там, где разрешает согласие; не в git. Участники в журнале — под
  псевдонимами (P01, P02 …), список «псевдоним ↔ человек» — отдельно у ответственного.

## Подготовка

| Что | Как |
|---|---|
| Камеры | основной поток (1080p) **и** substream (640×360), если камера умеет — оба пишем |
| Ракурсы | A: коридор сверху (2.5–3 м); B: вход/дверь; C: сбоку на уровне 1.5–2 м (лица) |
| Время | часы камер по NTP; в начале каждого дубля — хлопок + телефон с часами в кадре |
| Условия | день; вечер/плохой свет (свет приглушён); группа 3–6 человек; перекрытия (люди проходят между камерой и сценой) |
| Реквизит | маты; 3–4 разные сумки/рюкзака + 2 одинаковые; ноутбук; макет двери/панель из фанеры; стенд с плакатом; бумага/плёнка для закрытия камеры; фонарик; карта-пропуск и дверь/турникет со СКУД (для проходов) |
| Длительность дубля | 20–60 с: 5–10 с «до» + действие + 10–20 с «после» (нужно для правил с таймерами) |

## Сцены

Повторы: каждую сцену — **минимум 3 дубля × 2 ракурса**, разные участники; часть дублей — вечер или группа.
«Негатив» — похоже на инцидент, но им не является: на нём меряем ложные тревоги.

## Журнал записи (заполнять на площадке)

Шаблон — `docs/shooting_journal_template.csv`. Одна строка = одно действие в дубле:

| поле | пример |
|---|---|
| file | `camA_20261205_1412.mp4` |
| camera | `A` |
| scene_id | `O3` |
| take | `2` |
| start_s / end_s | секунды от начала файла: `14.0` / `31.5` |
| participants | `P03;P07` |
| light | `day` / `evening` |
| crowd | `1` / `group` |
| occlusion | `yes` / `no` |
| negative | `yes` для негативов |
| notes | `P07 забрал сумку P03, ушёл влево` |

Журнал — готовый черновик разметки событий для `eval_events.py` (шаг 10): после съёмок
только уточняем границы `start_s / end_s` по видео.

## Объём (оценка)

~45 сцен × 3 дубля × 2 ракурса ≈ 270 коротких дублей + W1 ≈ 1 ч обычной жизни.
При 6–8 добровольцах и двух операторах — 2 дня съёмок (день + вечер). Сначала база и лица,
затем новые функции.

## После съёмок

1. Копии файлов в хранилище команды (по согласию), sha256 в `data/manifest.csv`.
2. Разделить по **дублю/участникам** на dev и test (`make_splits.py`), test заморозить.
3. Перенести журнал в разметку событий, 10% проверяет второй человек.
